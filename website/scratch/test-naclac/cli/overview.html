Naclac CLI — Full Command Reference and Overview

The naclac CLI drives the full Solana development lifecycle — scaffold, compile, deploy, test, upgrade, and profile your programs from the terminal.

The naclac CLI is the primary interface for working with Naclac workspaces. It wraps the full development lifecycle — from scaffolding a new project and compiling Rust programs to SBF bytecode, to generating TypeScript client SDKs, deploying to any Solana cluster, and profiling compute unit usage. Every command is designed to reduce boilerplate and let you focus on program logic rather than toolchain ceremony.

Commands

CommandDescription
naclac init <name>Scaffold a new Naclac workspace
naclac add <name>Add a program to an existing workspace
naclac buildCompile to SBF and generate IDL + SDK
naclac generate(Re-)generate TypeScript SDK from IDL
naclac deployDeploy programs to the configured cluster
naclac testRun the TypeScript test suite
naclac upgradeUpgrade a deployed program
naclac verifyVerify on-chain binary matches local build
naclac idl initUpload IDL to on-chain account
naclac accountFetch and deserialize an on-chain account
naclac logsTail cluster logs
naclac expandExpand macros via cargo-expand
naclac profileProfile compute unit usage
naclac cleanClean build artifacts
naclac airdropAirdrop SOL to your wallet
naclac doctorCheck your environment

Global Options

Most commands automatically locate your workspace root by looking for a Naclac.toml file in the current directory or up to two levels above it. This means you can run commands from anywhere inside the workspace — the project root, a programs/ subdirectory, or a tests/ folder — and the CLI will resolve the correct workspace context without requiring you to cd to the root first.

If Naclac.toml cannot be found, the command exits immediately with a clear error message rather than operating on the wrong directory.

Key Pages

naclac init

Scaffold a new workspace with your chosen execution mode and full project structure.

naclac build

Compile to SBF, auto-sync program IDs, generate the IDL, and produce the TypeScript SDK.

naclac deploy

Deploy your compiled programs to localnet, devnet, testnet, or mainnet.

naclac test

Execute your TypeScript integration test suite with optional build-and-deploy sequencing.
