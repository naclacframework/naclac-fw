## What Is Naclac?

Naclac is a Solana smart contract framework built around three configurable execution modes — letting you trade development speed for raw on-chain performance depending on your program's requirements. Its procedural macro system eliminates boilerplate account validation and instruction dispatch while keeping you in full control of your program's logic.

## Get Started in Three Steps

<Steps>
  <Step title="Install the CLI">
    Run the one-line installer to get the `naclac` binary on your machine.

    ```bash
    curl -sSfL https://raw.githubusercontent.com/naclacframework/naclac-fw/main/.github/scripts/install.sh | sh
    ```
  </Step>
  <Step title="Scaffold a new workspace">
    Create a new workspace and choose your execution mode interactively.

    ```bash
    naclac init my_program
    ```
  </Step>
  <Step title="Build and deploy">
    Compile your program to SBF, generate the IDL, and deploy to the network.

    ```bash
    naclac build
    naclac deploy
    ```
  </Step>
</Steps>

## Execution Modes at a Glance

<CardGroup cols={3}>
  <Card title="Standard" icon="box" href="/concepts/execution-modes">
    **`solana-program` + Borsh.** Maximum compatibility with existing Solana tooling and libraries. Ideal for getting started quickly.
  </Card>
  <Card title="Optimized" icon="bolt" href="/concepts/execution-modes">
    **`solana-program` + Zero-Copy.** Bypasses the Borsh allocator — data is memory-mapped directly from the instruction buffer for lower compute usage.
  </Card>
  <Card title="Pinocchio" icon="microchip" href="/concepts/execution-modes">
    **`no_std` + Zero-Copy.** The highest-performance mode. All heap allocations are forbidden; CPI signer seeds are stack-allocated with `MaybeUninit`.
  </Card>
</CardGroup>
