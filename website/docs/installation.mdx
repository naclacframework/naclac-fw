Before you write your first Naclac program, you need the Naclac CLI on your machine and a working Solana development environment. This page walks you through every prerequisite, the CLI install script, and the `naclac doctor` command that confirms everything is wired up correctly.

---

## Prerequisites

Install these tools before running the Naclac installer. `naclac doctor` checks for each one and tells you exactly what is missing.

| Tool | Why it's needed |
|---|---|
| **Rust + SBF target** | Compiles your Rust program to Solana's BPF bytecode via `cargo build-sbf` |
| **Solana CLI** | Provides `solana-keygen`, cluster configuration, and the `solana-test-validator` |
| **Node.js** | Runs the generated TypeScript test suite |
| **Yarn** | Default package manager for the workspace's TypeScript dependencies |
| **`cargo-build-sbf`** | Solana's BPF toolchain wrapper; installed alongside the Solana CLI |

Install Rust with `rustup`:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

Install the Solana CLI (which also installs `cargo-build-sbf`):

```bash
sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
```

Install Node.js (v18 or later recommended) and Yarn:

```bash
# Node.js via nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.0/install.sh | sh
nvm install --lts

# Yarn
npm install -g yarn
```

## Install the Naclac CLI

<Steps>
  <Step title="Run the install script">
    Paste this one-liner into your terminal. The script detects your OS and architecture, downloads the correct pre-built binary from GitHub Releases, and places it at `$HOME/.local/share/naclac/bin/naclac`.

    ```bash
    curl -sSfL https://raw.githubusercontent.com/naclacframework/naclac-fw/main/.github/scripts/install.sh | sh
    ```

    Supported platforms:
    - Linux x86_64
    - macOS x86_64
    - macOS arm64 (Apple Silicon)
  </Step>

  <Step title="Add the binary to your PATH">
    The installer automatically appends the export line to your shell profile (`.bashrc`, `.zshrc`, or `.profile`). If you need to add it manually, or if you want to make it available in your current terminal session without restarting, run:

    ```bash
    export PATH="$PATH:$HOME/.local/share/naclac/bin"
    ```

    To persist this across sessions, add the line above to your shell profile.
  </Step>

  <Step title="Verify the installation">
    Confirm the binary is on your PATH and responding:

    ```bash
    naclac --version
    ```

    You should see output similar to `naclac 0.1.0`. If the command is not found, see the note below about restarting your shell.
  </Step>
</Steps>

<Note>
  The installer writes the `export PATH` line to your shell profile, but the current terminal session does not pick it up automatically. Either open a new terminal window, or run `source ~/.bashrc` (or `source ~/.zshrc`) followed by `hash -r` to reload your PATH without restarting.
</Note>

## Install a Specific Version

Pass the target version through the `VERSION` environment variable before piping to `sh`. The installer accepts any release tag from the GitHub Releases page.

```bash
VERSION=v0.1.0 curl -sSfL https://raw.githubusercontent.com/naclacframework/naclac-fw/main/.github/scripts/install.sh | sh
```

If the version string does not start with `v`, the installer prepends it automatically. If the specified tag does not exist, the script exits with an error before downloading anything.

## Verify Your Environment

Run `naclac doctor` from any directory to check that every required tool is installed and executable:

```bash
naclac doctor
```

Example output when everything is in order:

```
🩺 Running Naclac Environment Diagnosis...
  ✅ Naclac CLI Router (cargo-build-sbf): cargo-build-sbf 2.1.0
  ✅ Rust Compiler (rustc): rustc 1.81.0 (eeb90cda1 2024-09-04)
  ✅ Solana CLI (solana): solana-cli 2.1.0 (src:00000000; feat:3271415109, client:Agave)
  ✅ NodeJS (node): v22.13.1
  ✅ Yarn Package Manager (yarn): 1.22.22

🎉 Your environment is perfectly configured for Naclac!
```

`naclac doctor` checks each of the following in order:

1. **`cargo-build-sbf`** — the Solana BPF compiler wrapper
2. **`rustc`** — the Rust compiler
3. **`solana`** — the Solana CLI
4. **`node`** — Node.js runtime
5. **`yarn`** — Yarn package manager

Any item that fails is flagged with ❌ and a message telling you which binary could not be found or executed. Fix the flagged tools and re-run `naclac doctor` until you see the success message.

## Using nacvm (Version Manager)

If you work across multiple projects that pin different Naclac versions, or you want to test pre-release builds without overwriting your stable install, use `nacvm`. The `nacvm` binary installs to `$HOME/.nacvm/bin/nacvm` and manages isolated Naclac CLI versions independently of your system PATH.

See the [nacvm overview](/cli/nacvm/overview) for full installation instructions and usage reference.
