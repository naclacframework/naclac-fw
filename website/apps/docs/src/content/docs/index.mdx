## Why naclac

<CardGrid stagger>
	<Card title="Dual backend" icon="rocket">
		Write Solana programs against a standard `solana-program` backend or a
		hyper-optimized `pinocchio` backend, behind the same feature-gated API.
	</Card>
	<Card title="Codegen built in" icon="setting">
		`naclac generate` produces the on-chain IDL plus Rust and TypeScript
		clients directly from your program's source.
	</Card>
	<Card title="One CLI" icon="open-book">
		`init`, `build`, `deploy`, `test`, `verify`, and more — one workspace,
		one command-line surface.
	</Card>
	<Card title="Versioned tooling" icon="pencil">
		`nacvm` manages installed versions of the `naclac` CLI itself, the same
		way `rustup` manages Rust toolchains.
	</Card>
</CardGrid>
